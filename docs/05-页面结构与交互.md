# 页面结构与交互

> 本文档描述一期的页面结构、导航与关键交互规则。
> 数据模型对应 `02-数据库与同步.md`，提醒送达方式见 `04-技术选型.md`（本地通知）。

## 1. 导航

```
│  概览  │  记录  │  〔＋〕  │  用药  │  我的  │
```

底部 4 Tab + 中央"＋"动作按钮（非页面）。成员切换条常驻顶部，所有页面数据随当前成员切换。

## 2. 中央"＋"动作面板

半屏弹层，按**高频日常 vs 低频繁琐**分两组：

```
┌────────────────────────┐
│ 日常                    │
│  🩺 记血压   🩸 记血糖  │
│ ────────────────────── │
│ 阶段性                  │
│  💊 记用药变化          │
│  🏥 记复查（导入报告）  │
└────────────────────────┘
```

心率不单列入口，作为血压记录的可选附属项随表填写。

## 3. Tab 1 概览（首屏三卡）

```
┌──────────────────────────────────┐
│ 👤 爷爷 ▾              趋势与对比 >│
├──────────────────────────────────┤
│ 📌 便签                    全部 >  │
│  爷爷这周感冒，注意观察血压。      │
│  ⏰ 周五 18:00 提醒：取药（→妈妈） │
├──────────────────────────────────┤
│ 💊 今日用药                管理 >  │
│  早   氯沙坦钾片 1片 剩18片·约18天 │
│       二甲双胍   1片 剩42片·约21天 │
│  晚   二甲双胍   1片              │
│  睡前 阿托伐他汀 1片 剩9片·约9天   │
│  药   益肾健脾方 剩5副 这副第1天/共2天│
├──────────────────────────────────┤
│ 🏥 下次复查：2026-11-15（42天后）> │
└──────────────────────────────────┘
```

- **便签卡**：多条并存的家庭便签（可作待办勾选完成）。卡上显示最近 1~2 条，"全部 >"进便签列表（新建/编辑/完成）。每条便签可设**提醒时刻**与**提醒对象**（默认全家设备，可指定某台）；到点由目标设备本地通知触发。首屏不展示系统待办列表。
- **今日用药卡**：家庭实际执行的服药单（执行层），**与用药页的"当前方案"是两个东西，允许不一致**。
  - 西药项按 早/中/晚/睡前 分组（空时段隐藏），显示名称、每次用量、余量；余量 ÷ 每日用量自动给出"约 X 天"（纯算术展示，非医学提示）；
  - 中药项不进时段，显示为计数：剩余副数 + 当前这副进度（第 X 天 / 共 Y 天）；
  - 全部内容手工维护。"管理 >"进**今日用药管理页**：西药项（名称/每次用量/时段/余量+单位/每日用量）与中药项（名称/剩余副数/每副天数/已吃天数）的增删改。
- **复查卡** → 进该复查事件详情。数据来源：当前成员所有事件中最近的未来"下次复查日期"，无则显示引导文案。
- "趋势与对比"入口在右上角。

## 4. Tab 2 记录

顶部两段切换：**复查 ｜ 测量**

### 4.1 复查段

复查事件倒序列表 → 事件详情（多份报告 + 备注 + 关联用药变化 + 下次复查日期）→ 报告详情（渲染文字版为主视图 + 原件照片附件入口）→ **点任一指标行 → 指标历史页**（该指标历次复查数值，表格|折线）。

- 指标历史匹配规则：默认按报告**原文名称精确匹配**；加入重点清单的指标按别名归并（跨院不同名也能成线）。清单的价值是归并与仪表盘，不是查看资格。
- 当某指标仅匹配到 1 次记录时，指标历史页给出提示与"**加入重点清单**"按钮，作为跨院不同名断档的补救入口。

### 4.2 测量段

- **类型**：血压 / 血糖两个切换项。
- **周期选择**：自然月翻页（‹ 2026 年 9 月 ›）+ 快捷周期（近7天、近30天），默认当前月；只展示所选周期内的数据。
- **血压排版（日志表式）**：一行 = 一天（日期 + 星期），当日多次测量按时间先后并排，每条显示"高压/低压·心率"与下方时刻；当日条数超过一行宽度自动折行，不截断、不省略。
- **血糖排版（场景网格）**：表格，行 = 日期、列 = 场景（空腹/餐前/餐后/睡前/随机）；格内上行数值、下行时刻；同一场景当日多次上下叠放；无记录格显示 `·`。
- 点日行 → 当日明细（逐条时刻、数值、署名），可对单条**编辑**（修正手误，保留原录入署名）或**删除**（软删）。

### 4.3 移出项

用药变化节点不出现在本 Tab（在用药页"历史用药"中按阶段呈现，见第 5 节）。

## 5. Tab 3 用药（方案 · 档案层）

```
┌──────────────────────────────────┐
│ 👤 爷爷 ▾                        │
├──────────────────────────────────┤
│ 当前方案 · 长期 3 种（点卡片编辑） │
│ ┌──────────────────────────────┐ │
│ │ 氯沙坦钾片            [早]    │ │
│ │ 每次 50mg                    │ │
│ ├──────────────────────────────┤ │
│ │ 二甲双胍            [早][晚]  │ │
│ │ 每次 0.5g                    │ │
│ ├──────────────────────────────┤ │
│ │ 益肾健脾方      [中药][早][晚]│ │
│ │ 7 剂，每日一剂，水煎服        │ │
│ └──────────────────────────────┘ │
├──────────────────────────────────┤
│ 临时用药（辅助）                  │
│  连花清瘟胶囊  每次4粒 · 至 8/6   │
├──────────────────────────────────┤
│ 历史用药 ›（独立页）              │
│                                  │
│        [ ＋ 记用药变化 ]          │
└──────────────────────────────────┘
```

- **当前方案卡**是主体：药名 + 中西药标 + 时段 + 用法用量（中药在此写详细：剂数、煎服法）。**无余量、无日期**——方案是"现在在吃什么"的陈述，日期属于历史。点卡片 → 编辑全部信息（名称/用量/中西药/长期临时/时段/起止日期，填结束日期即停用）。
- **临时用药**为辅助区，无内容不显示。
- **历史用药 › 独立页**：按变化节点分段（"2026-08-15 起 · 至今"），每段列出该阶段的西药/中药清单；段头显示本次变化的**事由备注**与**关联复查**（可跳转至该复查事件）。
- **记用药变化**（核对式）：顶部选生效日期、填事由（自由文本备注）、选关联复查（可空）→ 当前用药逐条标记【停用】（划线）/【改量】（展开内联编辑用量与时段），可叠加、再点取消 → 下方新增药品/药方（中西药、长期临时、时段，临时需填止日）→ 一次保存，产生一条用药变化记录（停 X · 改 X · 增 X）。改量自动建立 supersedes 链。

## 8. 录入表单

- **记血压/血糖**：大数字键盘、时间默认"现在"可改、保存后自动返回；目标 ≤15 秒。血压表单内含心率可选填；血糖带场景选择（空腹/餐前/餐后2h/睡前/随机，记忆上次）。
- **记复查（导入）**：粘贴文本 → 解析预览 → 逐项核对 → 确认入库，四步；照片事后在事件详情补传（拍照/相册，自动压缩）。
- **记用药变化**：核对式，见第 5 节。入口：中央"＋"或用药页底部按钮。
- **今日用药管理**：概览 → 今日用药卡"管理 >"，见第 3 节。

## 9. 核心流程步数

| 流程 | 步数 | 路径 |
|---|---|---|
| 录一次血压 | 3 | ＋ → 记血压 → 保存 |
| 归档一次复查 | 5 | ＋ → 记复查 → 粘贴 → 预览核对 → 确认 |
| 复查后调药 | 4 | ＋ → 记用药变化 → 逐条标记/新增 → 保存 |
| 交代用药（交接场景） | 1 | 用药 Tab 直达 |
| 管理今日用药/更新余量 | 2 | 概览 → 管理 › → 点项编辑 |
| 查某指标变化（任意指标下钻） | 4 | 记录 → 复查事件 → 报告 → 点指标行 |
| 看病答"上次 ACR"（清单内） | 3 | 概览 → 趋势与对比 → 读数 |
| 出示报告原件 | 4 | 记录 → 复查事件 → 报告 → 附件 |
| 写便签提醒家人 | 4 | 概览 → 便签卡 → 新建 → 设时刻与对象 |
| 切换成员后操作 | 1+ | 顶部切换，之后同上 |
