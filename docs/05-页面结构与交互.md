# 页面结构与交互

> 本文档描述一期的页面结构、导航与关键交互规则（2026-09-08 全面对齐实现）。
> 数据模型对应 `02-数据库与同步.md`，提醒送达方式见 `04-技术选型.md`（本地通知）与本文 §9。

---

## 1. 导航

```
│  概览  │  记录  │  〔＋〕  │  用药  │  我的  │
```

底部 4 Tab + 中央"＋"动作按钮（非页面）。顶部为**居中成员气泡**（主题色底、成员名），点击弹出成员切换/添加；所有页面数据随当前成员切换。首配未完成时全应用只呈现「连接家庭服务器」页（§7）。

## 2. 中央"＋"动作面板

半屏弹层，按**高频日常 vs 低频繁琐**分两组：

```
┌────────────────────────┐
│ 日常                    │
│  🩺 记血压   🩸 记血糖  │
│ ────────────────────── │
│ 阶段性                  │
│  💊 记用药变化          │
│  🏥 记复查（置灰暂禁用） │
└────────────────────────┘
```

心率不单列入口，作为血压记录的可选附属项随表填写。「记复查」一期暂置灰（入口保留、不可用），复查入库走 App 内导入页（我的→HTTP 导入令牌或记录页入口待恢复）与外部 HTTP 通道。

## 3. Tab 1 概览

自上而下四块：

- **下次复查气泡**（置顶，悬浮气泡样式）：左"下次复查"右日期；**点日期弹滚轮选择器改期**（写回复查事件 next_checkup_date，02 §4.3 可改表）；无复查事件时提示先录入。
- **便签卡**：紧凑单行列表（最多 5 条未完成便签，行间细分隔线）；有提醒的行首黄色 ⏰（无提醒留占位保持对齐）；允许完整换行。"全部 ›"进便签列表（§8 便签）。
- **今日测量卡**：**两行四列占位气泡**——列=空腹/上午/下午/晚上（列头置顶），行=血糖/血压；格内显示当日该时段最近一次数值+时刻（血压不显示心率），空显"—"。**点气泡**→ 对应类型记录表单；**长按空气泡**→ 滚轮时间选择，设"每天"测量提醒（§9）。
- **今日用药卡**：表格化（表头：药品/用量/剩余/预计）；中药置顶且药品栏着色；西药按所属时段**逐时段各显示一行**（早/中/晚/睡前字样 + 左侧竖条按时段着色）。每行左侧勾选框（方框=打勾，**本机视觉状态、不写库、跨天自动清零**）；编辑一律进"管理 ›"（今日用药管理页，§8）。
  - 预计天数 = 剩余量 ÷ 每日用量（每日用量=全天总消耗，一天三次的药填 3 倍单次量）；
  - **低余量提醒**：余量 ≤ 1 天用量时，下次服药前 1 小时本机推送补药提醒（每味药只排一次，§9）。

## 4. Tab 2 记录

顶部两段切换：**复查 ｜ 测量**

### 4.1 复查段

- **重点指标对比**（顶部）：紧凑表格（行=清单项、列=**最近 5 次**复查，行列分割线，字号收紧）；"＋ 添加 ›"弹层：候选自动列出该成员全部报告指标名（已在清单的排除），也可手输别名。行可点 → 指标历史页。
- **复查事件列表**：倒序，行=日期+科室（有备注加一行灰字备注，无摘要行）→ 事件详情：标题=日期，备注卡（仅备注文本），本次用药变化卡（如有），报告列表 → 报告详情（渲染文字版 + 结论 + 附件计数）→ **点指标行进指标历史页**（紧凑数值行：日期·科室｜值，无折线）。
- 指标历史匹配规则：默认按报告**原文名称精确匹配**；加入重点清单的按别名归并。仅匹配到 1 次时给出提示与"加入重点清单"按钮。

### 4.2 测量段

- **类型**：血压 / 血糖两个切换项；**周期**：近 3 天 / 近 7 天 / 近 30 天 chips。
- **统计卡**：最新值（大字+日期）、条数、均值·最高·最低（纯算术）；下方按日数值行（日期+星期，当日多次按时刻并排，自动折行；血压条含心率，血糖条含场景）。
- **点日行** → 当日明细弹层（逐条时刻、数值、署名），单条可**编辑**（修正手误，保留原署名；追加型实现=软删旧+新建）或**删除**（软删）。

## 5. Tab 3 用药（方案 · 档案层）

- **当前方案卡**（主体）：药名 + 中西药标 + 时段 + 用法用量（中药写详细：剂数、煎服法）；**无余量、无日期**。点卡片 → 编辑全部信息。
- **临时用药**为辅助区，无内容不显示。
- **历史用药 › 独立页**：按变化节点分段（"2026-08-15 起 · 至今"），每段列出该阶段清单；段头显示**事由备注**与**关联复查**（可跳转）。
- **记用药变化**（核对式）：生效日期**滚轮选择**、备注（自由文本）、关联复查（FlowRow 换行排列，可空）→ 当前用药逐条标记【停用】/【改量】（内联编辑用量与时段）→ 新增药品/药方（中西药、长期临时、时段，临时需填止日）→ 一次保存产生变化记录（停 X · 改 X · 增 X），改量自动建立 supersedes 链。

## 7. 首配与账号

- **连接家庭服务器**（首配，未配置时全应用唯一页面）：只需**家庭口令 + 设备署名**（服务器地址内置）；提交后 auth 换 token → 全量下行 → 进入主界面。
- **服务器与账号**（我的 →）：服务器/署名/家庭 ID、同步状态（同步中/待上行 N 条/已是最新）、最近同步错误、家庭名（本机显示）编辑、立即同步、重新配置（清本机数据后重连）。

## 8. 录入表单与便签

- **记血压/血糖**：大数字键盘、**测量时间滚轮选择**（默认现在）、保存后自动返回；血压内含心率选填；血糖带场景选择（记忆上次）。
- **记复查（导入页）**：粘贴 JSON → **服务端 dry_run 预检**（显示将写入的报告/指标计数）→ 逐项核对 → 确认入库 → 增量下拉刷新。
- **便签**：列表页每条可勾选完成、可**删除**（软删同步）；新建：内容 + **日期时间滚轮合一选择**（可空）+ **单次/每天**重复 + 提醒对象（全家/指定设备）。
- **今日用药管理**：西药项（名称/每次用量/每日用量/余量+单位/时段）与中药项（名称/剩余副数/每副天数/已吃天数）的增删改。

## 9. 本地提醒（本机闹钟，不跨设备）

| 类型 | 触发 | 规则 |
|---|---|---|
| 便签提醒 | 选定日期+时刻 | 单次/每天；到点系统通知，点击进 App |
| 测量提醒 | reminders 表测量时刻 | 每天；概览网格长按/提醒设置页维护，本机与表对齐 |
| 补药提醒 | 余量 ≤ 1 天用量 | 下次服药前 1 小时，每味药只排一次 |

实现：AlarmManager + 通知渠道 + 开机重排；精确闹钟无权限时退非精确；API 33+ 首进申请通知权限。提醒在哪台设备创建在哪台响（服务器只存配置，不做跨设备响铃）。

## 10. 核心流程步数

| 流程 | 步数 | 路径 |
|---|---|---|
| 录一次血压 | 3 | ＋ → 记血压 → 保存 |
| 归档一次复查（App 内） | 4 | 导入页 → 粘贴 → 预检 → 确认 |
| 复查后调药 | 4 | ＋ → 记用药变化 → 逐条标记/新增 → 保存 |
| 交代用药（交接场景） | 1 | 用药 Tab 直达 |
| 管理今日用药/更新余量 | 2 | 概览 → 管理 › → 点项编辑 |
| 查清单内指标变化 | 2 | 记录 → 复查顶部表读数（点行进历史） |
| 查任意指标变化 | 4 | 记录 → 复查事件 → 报告 → 点指标行 |
| 改下次复查日期 | 1 | 概览气泡 → 滚轮选日期 |
| 写便签提醒家人 | 4 | 概览 → 便签卡 → 新建 → 选时刻与对象 |
| 设每天测量提醒 | 2 | 概览网格长按空气泡 → 选时间 |
| 切换成员后操作 | 1+ | 顶部气泡切换，之后同上 |
