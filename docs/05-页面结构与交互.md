# 页面结构与交互

> 本文档描述一期的页面结构、导航与关键交互规则（2026-09-08 全面对齐实现）。
> 数据模型对应 `02-数据库与同步.md`，提醒送达方式见 `04-技术选型.md`（本地通知）与本文 §9。

---

## 1. 导航

```
│  概览  │  记录  │  〔＋〕  │  用药  │  我的  │
```

底部 4 Tab + 中央"＋"动作按钮（非页面）。顶部为**居中成员气泡**（主题色底、成员名），点击弹出成员切换/添加；所有页面数据随当前成员切换。首配未完成时全应用只呈现「连接家庭服务器」页（§7）。

## 2. 中央"＋"动作面板

半屏弹层，按**高频日常 vs 低频繁琐**分两组：

```
┌────────────────────────┐
│ 日常                    │
│  🩺 记血压   🩸 记血糖  │
│ ────────────────────── │
│ 阶段性                  │
│  💊 记用药变化          │
│  🏥 记复查（置灰暂禁用） │
└────────────────────────┘
```

心率不单列入口，作为血压记录的可选附属项随表填写。「记复查」一期暂置灰（入口保留、不可用），复查入库走 App 内导入页（我的→HTTP 导入令牌或记录页入口待恢复）与外部 HTTP 通道。

## 3. Tab 1 概览

自上而下四块：

- **下次复查气泡**（置顶，悬浮气泡样式）：左"下次复查"右日期；**点日期弹滚轮选择器改期**（写回复查事件 next_checkup_date，02 §4.3 可改表）；无复查事件时提示先录入。
- **便签卡**：紧凑单行列表（最多 5 条未完成便签，行间细分隔线）；有提醒的行首黄色 ⏰（无提醒留占位保持对齐）；允许完整换行。"全部 ›"进便签列表（§8 便签）。
- **今日测量卡**：**两行四列气泡**——列为同一维度的测量时间段（早晨/上午/下午/晚上，列头置顶），行=血糖/血压；统一按 measured_at 归格：5–8 点=早晨 / 9–11 点=上午 / 12–17 点=下午 / 其余=晚上。格内显示该类型、该时间段下最近一次数值；同格多次时附"N次"。血糖同时显示其测量场景（空腹/餐前/餐后/睡前/随机），血压不使用"空腹"概念。空格显示"—"。手工录入、历史数据与 API 导入一律使用同一时间规则，不额外存储或读取概览时段标签。
- **本卡片只读展示**，录入统一走中央「＋」→ §8，测量提醒统一在"我的 → 提醒设置"维护，不在数据格上混入长按操作。
- **今日用药卡**：表格化（表头：药品/用量/剩余/预计）；内容来自当前有效用药方案，按所属时段**逐时段各显示一行**，**最左侧为时段气泡**（早/中/晚/睡前 气泡 + 字样，四时段各有颜色区分，同一时段多行合并为一个气泡跨行显示），其后依次为药品、每次用量、该时段理论剩余、该时段最早缺药时点。编辑一律进"管理 ›"（今日用药管理页，§8）。
  - 各时段从最近盘点量独立扣减；最晚服用截止时间为早 11:59、中 17:30、晚 20:30、睡前 23:59。预计值实时计算，不同步、不落库；
  - **低余量提醒**：余量 ≤ 1 天用量时，下次服药前 1 小时本机推送补药提醒（每味药只排一次，§9）。

## 4. Tab 2 记录

顶部两段切换：**复查 ｜ 测量**

### 4.1 复查段

- **重点指标对比**（顶部）：紧凑表格（行=清单项、列=**最近 5 次**复查，行列分割线，字号收紧）；"＋ 添加 ›"弹层：候选自动列出该成员全部报告指标名（已在清单的排除），也可手输别名。行可点 → 指标历史页；**长按行 → 确认后移出重点清单**（仅移出对比，报告与历史指标不受影响）。
- **复查事件列表**：倒序，行=日期+科室（有备注加一行灰字备注，无摘要行）→ 事件详情：标题=日期，**备注卡（统一可编辑：有备注点「编辑」修改、无备注点「添加备注」新增，多行输入后保存；清空保存即删除备注）**，本次用药变化卡（如有），报告列表 → 报告详情（渲染文字版 + 结论 + 附件计数）→ **点指标行进指标历史页**（紧凑数值行：日期·科室｜值，无折线）。
- 指标历史匹配规则：默认按报告**原文名称精确匹配**；加入重点清单的按别名归并。仅匹配到 1 次时给出提示与"加入重点清单"按钮。

### 4.2 测量段

- **类型**：血压 / 血糖等宽分段切换。
- **粒度**（独立居中胶囊）：**日 / 周 / 月** 三段；命中态青绿底。
- **周期导航**（粒度下方一行）：左圆按钮 ‹ / 右圆按钮 › / 居中标题（**标题可点击**弹日期选择器直接选日期）。右箭头在当前周期（含今天）时置灰。标题格式：日=`M月D日 周X`、周=`M月D日—M月D日`、月=`YYYY年M月`。
- **回到今天**：当不在当前周期时，标题右侧浮出灰色小字按钮 **回到今天**，点击回到今日。
- **统计摘要**（周期导航下方一行居中灰字）：`本日/本周/本月 X 次记录 · X 天有数据`，纯展示。
- **血糖场景筛选**（仅血糖，紧贴摘要下方单行）：全部 / 空腹 / 餐前 / 餐后2小时 / 睡前 / 随机；切换成员时恢复全部。
- **按天分组表**：血压四列（日期｜时间｜高压/低压 mmHg｜脉搏 次/分）、血糖四列（日期｜时间｜血糖 mmol/L｜测量标签）。同一天多次合并为一个日期组，日期倒序、同日时间升序；**周/月视图不显示无记录的日期**（避免空行铺满），日视图若无记录显示"暂无记录"。**异常值标红**：血压高压≥140 或低压≥90 整段红色，血糖≥11.1 mmol/L 整段红色。日期列显示月日 + 星期，当天显示"今天"。
- **列表区手势**：在数据列表上**左右滑动** = 翻上一/下一周期（右滑=上一周期/更早；左滑=下一周期/更近；达到今天时不可再左滑）。
- **列表底部提示**：灰色小字 `没有更多记录了 · 左滑查看上月`。
- **点有记录日期组或数值行** → 当日明细弹层（当前类型全部记录，逐条时刻、数值、署名），单条可**编辑**（追加型实现=软删旧+新建）或**删除**（软删）。明细较多时可滚动。

## 5. Tab 3 用药（方案 · 档案层）

- **当前方案卡**（主体）：药名 + 中西药标 + 时段 + 用法用量。西药录入“每次数量＋单位＋一天次数”，一天次数独立保存；保存时若次数与所选时段数不一致，留在当前页提示修正。中药和旧数据保留详细用法文本。**无余量、无日期**。点卡片 → 编辑全部信息。
- **临时用药**为辅助区，无内容不显示。
- **历史用药 › 独立页**：按变化节点分段（"2026-08-15 起 · 至今"），每段列出该阶段清单；段头显示**事由备注**与**关联复查**（可跳转）。
- **记用药变化**（核对式）：生效日期**滚轮选择**、备注（自由文本）、关联复查（FlowRow 换行排列，可空）→ 当前用药逐条标记【停用】/【改量】（西药内联编辑每次数量、单位、一天次数与时段；中药编辑详细用法）→ 新增药品/药方（中西药、长期临时、时段，临时需填止日）→ 一次保存产生变化记录（停 X · 改 X · 增 X），改量自动建立 supersedes 链，并将对应今日用药库存关联迁移到新条目。

## 7. 首配与账号

- **连接家庭服务器**（首配，未配置时全应用唯一页面）：只需**家庭口令 + 设备署名**（服务器地址内置）；提交后 auth 换 token → 全量下行 → 进入主界面。
- **服务器与账号**（我的 →）：服务器/署名/家庭 ID、同步状态（同步中/待上行 N 条/已是最新）、最近同步错误、家庭名（本机显示）编辑、立即同步、重新配置（清本机数据后重连）。

## 8. 录入表单与便签

- **记血压/血糖**（自上而下四段；**无"保存并再记一条"**；入口只有中央「＋」）：
  - 页面标题下不重复显示成员姓名。
  - ① **四列紧凑录入行**：记血压为「血压｜高压输入｜低压输入｜心率输入」，三个输入框等宽、等高、同行，框内以浅色“高压/低压/心率”提示，输入后消失，不重复显示 mmHg、次/分；记血糖为「血糖｜数值输入｜场景｜场景滚轮」，不显示 mmol/L，数值支持 1–2 位小数。血压没有场景或时段标签；
  - ② **测量时间**：**年 / 月 / 日 / 时 / 分 五个纵向滚轮**内嵌页面（**不弹窗**），默认取真实当前时刻；三行可见，选中行居中吸附，整体高度与列间距比通用滚轮紧凑；
  - ③ **备注**：保留外部标签，输入区域使用紧凑高度；
  - ④ **保存**按钮与内容区同宽，保存后**返回上一页**。
  - 概览"今日测量"仅根据测量时间归格（§3）；表单不要求用户重复选择展示时段，也不向 payload 写时段标签。
  - 全页与各选择器一律**上下滚动**（无左右滚动）。测量数值行是框内提示的特例，其余输入框仍使用框外标签。
  - 动效：页面进入 150–300ms 轻微淡入上移；输入聚焦时边框/背景轻量过渡；滚轮保持惯性并吸附到最近项；保存按钮保留涟漪并轻微缩放，不使用弹跳或大幅位移。
- **记复查（导入页）**：粘贴 JSON → **服务端 dry_run 预检**（显示将写入的报告/指标计数）→ 逐项核对 → 确认入库 → 增量下拉刷新。
- **便签**：列表页每条可勾选完成、可**删除**（软删同步）；新建：内容 + **日期时间滚轮合一选择**（可空）+ **单次/每天**重复 + 提醒对象（全家/指定设备）。
- **今日用药管理**：页面标题为“今日用药”，右侧同一水平线放正方形圆角“＋”按钮；移除副标题、说明文字及空列表提示。点击“＋”直接打开居中独立弹窗（单屏，无搜索前页），不使用底部抽屉或跳转用药编辑页；弹窗顶部即药品搜索框，默认列出当前有效、结构化用量完整且尚未加入的药品供滚动选择，输入关键词实时过滤；选定后同屏填写各药格盘点余量并保存。**四个时段（早/中/晚/睡前）固定展示**，仅该药实际服用的时段可编辑、其余置灰显示“不服用”。保存时同步各格盘点量与盘点时刻。移出今日用药只删除库存执行行，不影响用药方案；旧用药缺少结构化字段时暂不在弹窗列出。

## 9. 本地提醒（本机闹钟，不跨设备）

| 类型 | 触发 | 规则 |
|---|---|---|
| 便签提醒 | 选定日期+时刻 | 单次/每天；到点系统通知，点击进 App |
| 测量提醒 | reminders 表测量时刻 | 每天；概览网格长按/提醒设置页维护，本机与表对齐 |
| 补药提醒 | 余量 ≤ 1 天用量 | 下次服药前 1 小时，每味药只排一次 |

实现：AlarmManager + 通知渠道 + 开机重排；精确闹钟无权限时退非精确；API 33+ 首进申请通知权限。提醒在哪台设备创建在哪台响（服务器只存配置，不做跨设备响铃）。

## 10. 核心流程步数

| 录一次血压 | 3 | ＋ → 记血压 → 保存 |

| 切换成员后操作 | 1+ | 顶部气泡切换，之后同上 |
