## 4. 日常操作

```bash
# 状态与日志（服务器上，~/family-health/deploy 下）
docker compose ps
docker compose logs --tail=50 auth|sync|import|backup|caddy|pg
docker compose restart auth          # 重启单服务
docker compose up -d                 # 应用编排/环境变量变更

# 更新某个服务（本地 Windows 构建机）
cd server; $env:GOOS='linux'; $env:GOARCH='amd64'; $env:CGO_ENABLED='0'
go build -o build/sync/main ./functions/sync
scp -i <私钥> build/sync/main ubuntu@43.161.199.183:~/family-health/build/sync/main
ssh -i <私钥> ubuntu@43.161.199.183 "chmod +x ~/family-health/build/sync/main && cd ~/family-health/deploy && docker compose up -d --build sync"
# 注意：scp 后必须 chmod +x（Windows scp 丢执行位）

# 手动触发备份 / 查看备份
bash ~/family-health/deploy/backup-trigger.sh
ls ~/family-health/deploy/backups/backups/   # health-YYYY-MM-DD.pgdump，滚动 30 天
```

## 8. 已踩过的坑（勿再踩）

1. **PowerShell 5.1**：.ps1 必须 UTF-8 **带 BOM**（无 BOM 按 GBK 读，中文乱码报错）；内联命令里的中文会被包装层转码损坏——中文 SQL/JSON 一律走文件。
2. **PowerShell 函数返回 `byte[]` 会被枚举展开**：HTTP 字节体会被毁，返回时加逗号（`return ,$bytes`）。
3. **scp 丢 Linux 执行位**：上传二进制后必须 `chmod +x` 再构建镜像。
4. **PowerShell 管道写 SSH**：会注入 UTF-8 BOM（曾写坏 authorized_keys）；传公钥用 scp 文件方式。
5. **AGP 9 内置 Kotlin**：不得再应用 `org.jetbrains.kotlin.android`；KSP 需要 `gradle.properties` 里 `android.disallowKotlinSourceSets=false`。
6. **Compose 尾随 lambda**：组件最后一个参数若是 `@Composable` 内容，尾随 lambda 会绑错（FChip 事故）；回调必须放末位参数。
