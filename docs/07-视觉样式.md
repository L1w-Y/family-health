请按本规范统一现有项目的视觉样式。核心目标是：清晰、克制、易读，使用深青色作为交互主色，搭配白色组件和浅灰背景。


只修改：颜色、字体及字号字重、间距、圆角、边框、阴影、图标视觉风格、已有组件的视觉状态。
保留现有页面布局、布局容器、模块顺序、导航结构、表格列数与列宽比例、字段、文案、数据和业务逻辑。不新增、不删除、不合并、不拆分任何功能或信息模块。不把表格改成卡片，不把列表改成网格，不新增趋势图，不改变组件交互方式。

允许微调现有容器内部留白和同级元素间距，但不得因此改变分栏、信息排列方向、滚动区域、按钮位置或固定定位方式。空间不足时保留原布局约束，不通过重新排版解决。

以下尺寸是视觉基准，不是要求把所有控件强行改成同一尺寸。已有固定尺寸承担布局作用时优先保留。发现必须修改布局才能解决的问题，只记录问题，不自行扩大修改范围。

| textSecondary | #667782 | 次级说明、时间、辅助信息、未选中的导航文字 |

使用规则：

- 主色用于操作与选中状态，普通信息以深色正文呈现，不把所有标题、数字都染成青色。
- 一个区域内沿用现有主次操作关系：主操作深青底白字，次操作浅灰底深色字，轻量操作使用青色文字。
- 不根据血压、血糖或化验数值添加红黄绿分级、异常色、风险色或医学提示。
- 表单错误色仅用于项目已有的输入错误反馈，不新增医学阈值判断。
- 不使用渐变、玻璃模糊、发光边框、大片高饱和装饰色。
- 本规范为浅色主题。如项目已有深色主题，保持其可用，不把浅色值直接套入深色模式，也不擅自新增深色主题。
- 若项目启用了跟随壁纸等动态配色，不应让其覆盖本次明确指定的主色；使用项目现有主题机制集中管理。

## 2. 字体与字号

使用系统无衬线字体，中文采用系统默认中文字体。不引入装饰字体，不额外下载字体。

Android 原生实现：尺寸用 dp，字号用 sp，保留系统字体缩放。若项目采用其他技术栈，使用该框架的语义样式和字体缩放机制。以下数字按逻辑尺寸理解，不按设备物理像素换算。

| 层级 | 基准字号 | 字重 | 用途 |
|---|---:|---:|---|
| 页面主标题 | 23sp | 700 | 现有页面标题 |
| 表单页标题 | 21sp | 700 | 已有录入、编辑页面标题 |
| 模块标题 | 17sp | 600 | 卡片区或信息区标题 |
| 药品名称等主要条目标题 | 18sp | 600 | 需要快速识别的条目名称 |
| 普通正文、输入内容 | 16sp | 400 | 正文和表单内容 |
| 表单标签、表格文字 | 14sp | 500或400 | 已有字段标签、表格文字 |
| 主按钮文字 | 16sp | 600 | 已有主要操作 |
| 次按钮、切换项文字 | 14–15sp | 600 | 已有次级操作与切换控件 |
| 辅助说明、单位 | 12sp | 400 | 非关键补充信息 |
| 重要测量数值 | 20–23sp | 600 | 已经被突出展示的数值 |

使用规则：

- 同一种语义在各页面采用相同字号和字重，避免一页一个标准。
- 正文行高约为字号的1.5–1.7倍；短标题约为1.25–1.4倍，确保中文上下不被裁切。
- 650字重若平台不支持，统一使用600，不额外模拟字体描边。
- 中文使用默认字间距，不增加大幅字距，也不使用负字距压缩内容。
- 日期、时间和测量数字在字体支持时使用等宽数字特性；中文仍用原字体。
- 不使用删除线表示已服用；药名、剂量始终可读。
- 本次将过小的辅助文字提升至12sp基准；若影响现有布局，不删除或截断内容来迁就字号，应记录冲突。
- 不通过固定文本容器高度、关闭字体缩放来强行保持外观。

## 3. 间距

基础间距采用4dp步进：4、8、12、16、20、24、32dp。

| 用途 | 建议基准 |
|---|---:|
| 紧密关联的图标与文字 | 6–8dp |
| 标题与对应辅助说明 | 4–6dp |
| 字段标签与输入框 | 8dp |
| 同一组件内部的关联内容 | 8–12dp |
| 普通卡片内边距 | 14–16dp |
| 同级卡片之间 | 12dp |
| 相邻表单字段之间 | 16dp |
| 已有不同信息组之间 | 20–24dp |
| 页面内容左右留白 | 16dp基准，仅在不改变现有布局约束时统一 |

使用规则：

- 仅调整现有元素的 margin、padding 或框架对应间距属性，不增加新的布局层级。
- 同级元素的左右边缘统一对齐，文字与边框之间留白一致。
- 标签与其内容更靠近，不同信息组之间稍远，关系通过距离表达。
- 不因采用本规范而新增大面积空白、拉高整张卡片或缩小表格可用空间。
- 既有表格列宽、固定按钮位置、滚动范围及系统安全区处理保持不变。

## 4. 组件样式

### 卡片

- 白色背景，15dp圆角，1dp浅色边框（divider）。
- 普通卡片不加阴影，使用留白与细边框建立边界。
- 已有弹层或悬浮组件可保留极轻阴影，避免厚重投影。
- 不为原本没有卡片的区域新增卡片包裹。

### 按钮

- 主按钮：primary填充，onPrimary文字，11dp圆角，16sp/600文字。
- 次按钮：surfaceVariant填充，textPrimary或现有深色文字，11dp圆角。
- 文字按钮：透明背景，primary文字，保持原图标与文字位置。
- 按下态使用轻微压暗或平台原生反馈，不做位移、放大或弹跳。
- 禁用态使用disabledContainer和disabledContent，不同时把整个按钮透明度大幅降低。
- 常规触控区域以至少48dp为目标；已有布局不够时先保留结构，报告触控区域不足，不挪动按钮。

### 输入框与文本域

- 白底，1dp outline边框，11dp圆角；输入文字16sp。
- 内边距约12–14dp，标签14sp，标签与输入框间距8dp。
- 聚焦态使用primary边框，可由1dp加至2dp，但外尺寸不能跳动。
- 错误态只映射现有校验逻辑，使用inputError边框及错误文字。
- 保留原键盘类型、单行/多行设置、校验规则和日期选择方式。
- 不新增占位示例、说明或字段；已有文案保持原样。
- **紧凑测量录入行例外**：记血压的高压/低压/心率和记血糖的数值框允许使用字段名作为框内浅色提示，输入后消失；同行输入框必须等宽、等高、同圆角，焦点态在 150–300ms 内轻微改变边框与背景，不使用胶囊形或大幅缩放。

### 滚轮与动效

- 日期时间滚轮与场景滚轮均显示上/中/下三行，中心行吸附选中；中心使用 primaryContainer 浅底和 primary 深色文字，非选中行使用 textMuted 并降低字重。
- 场景滚轮比日期时间滚轮更矮；测量录入页的日期时间滚轮可在不改变五列功能的前提下压缩单行高度和列间距。
- 页面进入使用 150–300ms 淡入与短距离上移；按钮按下保留平台涟漪并允许约 1–2% 轻微缩放。禁止弹跳、闪烁和大幅位移。

### 分段切换控件

- 外层浅灰底，11dp圆角，内部留白4dp。
- 已选项白底、primary文字、8dp圆角；未选项透明底、textSecondary文字。
- 如需阴影，仅选中项使用很轻的阴影。
- 不改变选项数量、排列方向、默认选项或切换行为。

### 标签与多选时段

- 已有只读标签：primaryContainer背景，onPrimaryContainer文字，6dp圆角，12–13sp。
- 中性标签：surfaceVariant背景，textSecondary文字。
- 可点击的选项保持原触控区域；选中时使用浅青底＋青色边框和文字。
- 只读标签与可操作选项通过原有边界、状态区分，不给只读标签新增交互。

### 表格

- 表头背景surfaceVariant，文字textSecondary；数据区白底，正文textPrimary。
- 使用1dp横向浅分割线，避免加粗外框或深色密集网格。
- 保持现有列宽、行列顺序、单元格合并方式、对齐方式与滚动行为。
- 在不改变当前密度的前提下统一单元格内边距，测量值可沿用已有字重强调。
- 缺失值保留现有表达方式，不用0代替，不填补、不合并测量值。
- 不新增列高亮、数据分级或额外汇总；已有选中态才映射对应颜色。

### 复选框

- 未选中：白底＋清晰的灰色边框。
- 选中：primary填充＋白色勾选图标。
- 外观建议6–7dp圆角；保留原组件形状约束及点击区域。
- 不改变勾选与业务状态的对应关系，不新增自动勾选。

### 导航和图标

- 现有导航区域白底，顶部1dp divider分割线。
- 选中图标及文字使用primary，未选中使用textSecondary。
- 沿用项目现有图标库，统一为相近的线性风格，约1.5–2dp视觉线宽，常规图标20–24dp。
- 不替换导航含义、不新增图标库依赖、不改变导航项、顺序、位置或中央按钮形态。
- HTML预览里的手机边框、模拟状态栏和桌面介绍区域不是应用组件，不需要实现。

## 5. 给开发 AI 的执行要求

1. 先读取项目现有规范、主题、字体、公共组件与样式定义，识别可复用的现有视觉变量。
2. 优先修改主题层和共享组件；已有组件可以满足要求时，不重写页面或组件实现。
3. 将上述颜色、字体、间距、圆角统一为可复用的语义变量，保留项目原来的架构及依赖。
4. 只将这些样式映射到现有界面，不套用任何新的页面布局方案，也不要从参考HTML复制页面结构。
5. 如存在无法同时满足样式和原布局的冲突，保留原布局，列出冲突；不要擅自裁切药名、剂量、日期或数值。
6. 修改后检查不同页面的同类组件是否一致，以及文字是否重叠、被截断，选中/禁用/聚焦状态是否清楚。
7. 保持已有功能可用；执行项目必要的构建与检查，提供修改前后相同页面、相同尺寸的截图对照。
8. 最终说明修改了哪些主题或共享样式文件，以及仍存在的视觉问题。不要改动数据模型、接口、业务规则或导航流程。

验收标准：页面还是原来的页面，信息和操作仍在原来的位置，但颜色、文字层级、留白、边框与组件状态已经统一。
