# 技术选型（v2.0）

---

## 1. 已确认决策

| 决策点 | 结论 |
|---|---|
| 服务端形态 | **腾讯云开发 CloudBase**：免费体验版起步（3,000 资源点/月，每 6 个月手动续期），用量超出或求省心时升个人版（19.9 元/月，40,000 点/月） |
| 数据库 | **环境内托管 PostgreSQL（共享实例，按使用计费、不用不计费）**——创建环境时数据库类型选 PostgreSQL，选定不可改 |
| 身份与鉴权 | 无账号体系：家庭口令 + 设备署名 → 设备 token（对应 02 文档 devices 表） |
| 提醒 | **本地通知**（各设备同步提醒配置后自行调度），一期不接任何推送通道 |
| 域名 / 备案 | 均不需要（云函数 HTTP 触发器使用平台默认域名） |
| 短信 / 推送服务 | 均不需要（方案层面消除） |

## 2. 总体架构

```
Android App（Kotlin + Compose + Room 本地镜像 + 本地通知）
   │ HTTPS
   ├─ auth   云函数：家庭口令校验 → 签发设备 token（哈希入库）
   ├─ sync   云函数：增量同步（下行）+ 幂等写入（上行）
   ├─ import 云函数：导入格式 v1 校验入库；挂 HTTP 触发器，供外部脚本/curl 直调
   ├─ export 云函数：按成员导出 JSON + 附件打包（临时下载链接）
   ├─ backup 云函数：定时触发，全量 dump 数据库到云存储（滚动保留 30 天）
   ├─ 托管 PostgreSQL（共享实例，02 文档表结构原样落地）
   └─ 云存储（报告照片原件，App 端压缩后上传）

外部 AI / 脚本 ──HTTPS──> import 云函数（默认域名，免备案，Bearer token 鉴权）
```

## 3. 选型清单

| 层 | 选择 | 说明 |
|---|---|---|
| Android 客户端 | Kotlin + Jetpack Compose + Room + WorkManager/AlarmManager | 无 Kotlin 经验，但 AI 辅助开发可补；Compose 是 AI 生成质量最高的 Android 技术栈；Room 做本地镜像缓存与离线查看 |
| 后端 | 云函数（Go 运行时） | 主场语言；按调用量计费，家庭用量几乎不超额 |
| 数据库 | 托管 PostgreSQL（共享实例） | 02 文档表结构原生落地（含 jsonb）；seq 用 PG 序列；按使用计费，家庭月耗约 3,000~9,000 资源点 |
| 照片存储 | 云存储 | 个人版含约 50GB；家庭年增量约 200MB，十年用不满 |
| 鉴权 | 自研设备 token：auth 函数签发、哈希存储、请求头携带 | 与 02 文档 devices 表、03 文档 `Authorization: Bearer` 约定一致 |
| 导出/备份 | 云函数生成 JSON（与导入格式 v1 同字段）+ 附件打包 | "导出物可再导入"是防厂商绑定的核心保险 |

## 4. PostgreSQL 落地要点（与 02 文档的关系）

02 文档的表结构即逻辑模型，在托管 PG 上**原样建表**，无需适配：

1. jsonb 列（times、aliases、payload、dose_slots 等）使用原生 JSONB；
2. 全局 seq：PG 序列（`CREATE SEQUENCE sync_seq`），每次写入在事务内取号赋值；
3. 导入批次原子性：单数据库事务完成"校验通过 → 事件 + 报告 + 指标 + 附件元数据"整体写入，失败即回滚，无需应用层补偿；
4. 附件二进制不入库：attachments 表存元数据 + 云存储 fileID；
5. 连接方式：云函数经环境内网直连（环境变量注入连接串）；M1 第一天用 curl 验证连通性与计费触发行为。
