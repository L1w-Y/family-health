## 1. 已确认决策

| 决策点 | 结论 |
|---|---|
| 服务端形态 | **腾讯云轻量应用服务器（香港·锐驰型 2核1G，40 元/月）+ Docker Compose 自建**：全家桶 6 容器单机运行 |
| 数据库 | **自建 PostgreSQL 16（Docker 容器）**：账号密码自控，仅容器内网可达，不暴露公网 |
| 身份与鉴权 | 无账号体系：家庭口令 + 设备署名 → 设备 token（对应 02 文档 devices 表） |
| 提醒 | **本地通知**（各设备同步提醒配置后自行调度），一期不接任何推送通道 |
| 域名 / 备案 | 香港免备案；免费动态域名（DuckDNS）+ Caddy 自动 HTTPS；不绑域名时纯 IP + HTTP 亦可运行 |
| 短信 / 推送服务 | 均不需要（方案层面消除） |

> **2026-09-07 部署形态变更**：原方案为 CloudBase 云托管 + 环境内托管 PG。实测共享集群不向云托管开放 PG 协议直连（数据库密码仅独享集群提供，重置/查看均被锁），REST/PostgREST 路线需重写整个 store 层且丢失事务与序列，故整体迁至轻量服务器自建。**后端代码零改动**（仍为 Go 二进制 + pgx 直连），仅部署载体变化。

## 2. 总体架构

```
Android App（Kotlin + Compose + Room 本地镜像 + 本地通知）
   │ HTTPS（Caddy 自动证书；验证期可用 HTTP）
   ▼
Caddy 反向代理（:80/:443，按路径分发，自动签发/续期证书）
   ├─ /auth           → auth   容器：家庭口令校验 → 签发设备 token（哈希入库）
   ├─ /sync           → sync   容器：增量同步（下行）+ 幂等写入（上行）
   ├─ /api/v1/import  → import 容器：导入格式 v1 校验入库，供外部脚本/curl 直调
   ├─ backup  容器：不经 Caddy 暴露；宿主机 cron 每日触发，pg_dump → 本地磁盘（滚动 30 天）
   ├─ pg      容器：PostgreSQL 16，仅容器内网（02 文档表结构原样落地）
   └─ export 容器：按成员导出 JSON + 附件打包（M3 实现）

本地磁盘卷：PG 数据（pgdata）、备份（deploy/backups）、报告照片原件（一期）

外部 AI / 脚本 ──HTTPS──> import 容器（Bearer token 鉴权）
部署形态：腾讯云轻量应用服务器（香港）单机 Docker Compose，编排见 server/deploy/docker-compose.yml
```

## 3. 选型清单

| 层 | 选择 | 说明 |
|---|---|---|
| Android 客户端 | Kotlin + Jetpack Compose + Room + WorkManager/AlarmManager | 无 Kotlin 经验，但 AI 辅助开发可补；Compose 是 AI 生成质量最高的 Android 技术栈；Room 做本地镜像缓存与离线查看 |
| 后端 | Go 容器（单机 Docker Compose） | 主场语言；镜像本地交叉编译、服务器构建，行为与本地验证完全一致 |
| 数据库 | 自建 PostgreSQL 16（Docker） | 02 文档表结构原生落地（含 jsonb）；seq 用 PG 序列；密码自控，绕开托管平台能力边界 |
| 照片存储 | 服务器本地磁盘卷 | 40GB SSD；家庭年增量约 200MB，十年用不满；二期再评估对象存储 |
| 鉴权 | 自研设备 token：auth 签发、哈希存储、请求头携带 | 与 02 文档 devices 表、03 文档 `Authorization: Bearer` 约定一致 |
| 导出/备份 | backup 容器 + 宿主机 cron 每日触发 | pg_dump 落本地磁盘滚动 30 天；"导出物可再导入"是防厂商绑定的核心保险 |

## 4. PostgreSQL 落地要点（与 02 文档的关系）

02 文档的表结构即逻辑模型，在托管 PG 上**原样建表**，无需适配：

1. jsonb 列（times、aliases、payload、dose_slots 等）使用原生 JSONB；
2. 全局 seq：PG 序列（`CREATE SEQUENCE sync_seq`），每次写入在事务内取号赋值；
3. 导入批次原子性：单数据库事务完成"校验通过 → 事件 + 报告 + 指标 + 附件元数据"整体写入，失败即回滚，无需应用层补偿；
4. 附件二进制不入库：attachments 表存元数据 + 云存储 fileID；
5. 连接方式：服务容器经 Docker 内网直连 PG（`sslmode=disable`，仅容器内网可达、不暴露宿主机端口，内网明文无风险）；连接串由 docker-compose 环境变量注入。
