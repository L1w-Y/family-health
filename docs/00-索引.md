## 3. 文档变更规则

1. 行为变更：先改本目录对应契约 → 改代码 → 回本表核对映射是否仍成立（新增模块必须加行）。
2. 文档内不写改动记录；文档即当前状态。
3. 映射表允许"代码位置"为空（表示尚未实现），不允许已实现但无映射。
